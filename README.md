# 将棋 webxdc

Delta Chatのチャット内で遊べる、平手将棋のミニアプリです。ひとり用のCPU対戦と、同じチャットにいる相手とのオンライン対戦に対応しています。

アプリのバージョンは **1.0.0** です。README更新日：2026年10月18日。

## このアプリの特徴

- 日本語の画面と、スマートフォンでも操作できる9×9の将棋盤。
- CPU対戦で先手・後手を選択可能。
- チャット相手との募集・参加・観戦・投了・先後交代での再戦。
- 駒の選択、合法な移動先の表示、持ち駒の選択と駒打ち、成りの選択。
- オンライン対局を受信済みの更新履歴から復元。
- `index.html`、`manifest.toml`、`icon.png` の3ファイルで構成した自己完結型の `.xdc`。

オンライン対戦では、着手などの更新をDelta Chatのwebxdc APIに渡します。専用の対戦アプリサーバーを運用する必要はありません。アプリから外部ネットワークへ直接通信する処理もありません。相手とのやり取りには、Delta Chat側で送受信できる環境が必要です。

完成したファイルは `outputs/` にあります。

| ファイル | 内容 |
| --- | --- |
| `shogi-1.0.0.xdc` | Delta Chatで開くアプリ本体 |

## チャット相手と遊ぶ

1. Delta Chatで相手とのチャットを開き、`shogi-1.0.0.xdc` をファイルとして添付して送ります。
2. 双方が、**同じチャットの同じアプリ投稿**を開きます。別々に添付したアプリ同士では対戦できません。
3. 双方が「チャット相手と対戦」を選びます。
4. 1人が「先手で募集」または「後手で募集」を押します。
5. もう1人が「参加する」を押します。更新が届くまで待ちます。
6. 自分の番になったら、自分の駒を選び、緑の印のマスを押して指します。

同じ投稿で同時に進められる対局は1つです。対局中に開いた第三者は観戦できます。双方が同時に募集した場合は、自動で組み合わせます。始まったら画面で自分の先後を確認してください。

### 駒を動かす 持ち駒を打つ

自分の駒を押すと、選択した駒と合法な移動先が緑色で表示されます。移動先を押すと着手が確定します。同じ駒をもう一度押すと選択を解除できます。

持ち駒は「歩 ×2」のように表示されます。そのボタンを押し、緑の印の空きマスを押すと打てます。

成りを選べる場合は「成る」「成らない」が表示されます。「選び直す」で着手前に戻れます。行き所がなくなる歩・香・桂は自動で成ります。

### 投了 再戦 引き分け

- 「投了」を押し、3秒以内に「本当に投了する？」をもう一度押すと終局します。
- 終局後の「もう一度（先後を交代）」で、同じ相手との再戦が直ちに始まります。相手の承諾画面はないため、先にチャットで相談してください。
- オンラインでは、双方が同じ局面で「引き分けを提案」「引き分けに同意」を押すと引き分けになります。着手すると提案は解除されます。
- 「メニューに戻る」だけでは、オンライン対局は終了しません。

## CPUと遊ぶ

「CPU対戦（あなたが先手）」または「CPU対戦（あなたが後手）」を選びます。後手を選んだ場合はCPUが先に指し、盤は自分の駒が下になる向きで表示されます。

CPUは初心者の練習用です。駒の価値と相手の次の応手を中心に判断する簡易的な探索で、長い詰み筋や囲い、長期的な作戦は得意ではありません。級位・段位による棋力評価はしておらず、強さの設定は1種類です。

「最初から」で同じ先後のままやり直せます。CPU戦の「引き分けにする」は、その場で練習を終了します。CPU戦の途中経過は、アプリを閉じると失われます。

## 採用ルール

| 項目 | 対応 |
| --- | --- |
| 駒の動き | 全種類の駒と成駒、遮蔽、桂の跳躍に対応 |
| 捕獲と駒打ち | 取った成駒は元の駒として持ち駒に加算 |
| 成り | 敵陣3段への出入り・敵陣内の移動で選択。必要な場合は強制成り |
| 王手と詰み | 自玉を王手にさらす手を拒否し、詰みで自動終局 |
| 二歩 | 同じ筋の自分の未成の歩を検査。と金は数えない |
| 行き所のない駒 | 歩・香の最終段、桂の奥2段への不正な駒打ちを拒否 |
| 打ち歩詰め | 歩を打って直ちに相手を詰ませる手を拒否 |
| 千日手 | 盤面・双方の持ち駒・手番が同じ局面が4回で引き分け |
| 連続王手の千日手 | 対象の反復区間で王手を続けた側の負け |
| 持将棋 | 点数計算・入玉宣言・500手での自動終局は未実装。双方合意の引き分けで対応 |
| 王手でない合法手なし | アプリ独自の扱いとして引き分け |

持ち時間、待った、駒落ち、棋譜の書き出しはありません。

## 通信と保存

オンライン対局は `sendUpdate` と `setUpdateListener` を用い、受信済みのイベントから復元します。手番の参加者、手数、直前の局面、合法手を検証します。重複したイベントは画面側で除外します。

到着順の違う更新を共通の順番で処理するため、論理時刻・送信者ID・イベントIDの順で履歴を再計算します。競合する更新が遅れて届いた場合、暫定的な表示が変わることがあります。非常に長い履歴での性能は未計測です。

更新内の送信者IDは自己申告です。改造クライアントによるなりすましを防ぐ独自の認証機能はありません。信頼できる相手との利用を想定しています。

通常のブラウザで `index.html` を開くと、説明用のテスト表示になります。この表示では別タブや他端末との対戦はできません。
